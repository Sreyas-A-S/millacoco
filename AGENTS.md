# Decisive Execution & Anti-Overchecking Rules

1. **Direct Execution First**: When the user provides a direct fix or request (e.g., style tweaks, color changes, asset updates, direct UI changes), locate the target line and apply the edit immediately. Do not conduct exhaustive investigations, exploratory script runs, or multi-step analysis on straightforward tasks.
2. **Single-Check Limit**: Perform at most one targeted check to locate the relevant code. If the target is obvious or directly described, edit immediately.
3. **No Unsolicited Secondary Verifications**: After applying a straightforward fix, do not trigger browser subagents, repetitive command checks, or multi-file inspections unless requested.
4. **Respect User Momentum**: Keep responses concise and focused on the change made.
